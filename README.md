OJT PLACEMENT AND MANAGEMENT SYSTEM



“This system manages On-the-Job Training (OJT) placements, from student applications to company coordination and progress monitoring. It also tracks student status, monitors performance, and records reports.”

OJT placements can be assigned to students, companies, and supervisors, with dates, status, and required/completed hours tracked in the placement list. To create the placement tables in a local database, run `python manage.py migrate`.
